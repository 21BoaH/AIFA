Project Background & Scope

Problem Statement & Objectives

Investigating how client-side edge computer vision can eliminate the barrier to injury-free resistance training without specialized sensors.

The Biomechanical Challenge

Improper exercise kinematics in resistance training frequently lead to musculoskeletal injury and inefficient neuromuscular recruitment. Beginners often lack access to qualified supervision or immediate kinematic form feedback.

Edge Computer Vision Solution

By extracting 33 full-body 3D skeletal landmarks at 30+ frames per second, the system computes inter-joint vectors in real time, detecting eccentric/concentric phases and evaluating depth and range of motion.

Privacy-Preserving Architecture

All inference is executed client-side using WebAssembly and WebGL acceleration. Zero raw video frames or biometric telemetry are transmitted to any remote servers, ensuring absolute user data privacy.

Technical Implementation

System Architecture & Pipeline

A deterministic four-phase pipeline translating raw webcam video into quantified repetition counts and biomechanical posture cues.

  1. Stage 01

    Video Frame Ingestion

    Captures client video stream via the HTML5 getUserMedia WebRTC API, streaming live camera frames directly onto a hidden DOM video buffer at native device refresh rates.

  2. Stage 02

    MediaPipe Pose Inference

    Runs Google's lightweight convolutional pose landmarker model in the browser to infer 33 key landmark coordinates (X, Y, Z normalized screen coordinates and visibility confidence scores).

  3. Stage 03

    Vector Joint Trigonometry

    Calculates acute joint angles between adjacent anatomical segments (Shoulder-Elbow-Wrist, Hip-Knee-Ankle) using two-argument arctangent formulas (Math.atan2) mapped to degrees.

  4. Stage 04

    Finite State Machine

    Repetition logic operates on a state machine (START → DOWN → UP). Repetitions are verified and incremented only when anatomical threshold requirements are met.
